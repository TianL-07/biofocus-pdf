# BioFocus

一个为科研论文阅读设计的 Windows PDF 阅读工具。用逐行聚焦减少干扰，把高亮、笔记、翻译和查词记录留在同一处。另附可本机运行和部署的网页开发版。

## Windows 使用

从 [Releases](https://github.com/TianL-07/biofocus-pdf/releases) 下载 Windows 压缩包，解压后运行 `BioFocus.exe`。请保留同一目录内的 DLL、`bridge.js` 和 `app/`，不要只移动 EXE。

运行环境：Windows 10 / 11、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。应用无需 Node.js。WebView2 使用系统安装并更新的运行环境。

### 文献文件夹

首次启动时，若桌面存在“文献阅读”文件夹，应用会直接连接它，并扫描子目录中的 PDF。也可以点击文献库的文件夹标题更换目录。新增、移除或修改文件后自动刷新。

- 点击文件夹条目会直接读取原 PDF，不复制整份文件进应用数据库。
- 高亮、笔记、词汇、提问和进度保存在应用自己的本机存储中。
- 文献按内容哈希识别，相同内容的文件可以沿用阅读记录。
- 修改或替换 PDF 的内容后会视为新的文献，避免把旧批注错误地套到新内容上。
- 原文件不会被改写；移除“我的文献”中的阅读记录也不会删除文件夹里的原 PDF。
- 扫描最多递归 10 层、5000 个 PDF，不跟随符号链接。单篇大小上限 150 MB。

## 功能

| 功能 | 当前行为 |
| --- | --- |
| 逐行聚焦 | 聚焦框外遮暗，支持 1–12 行；双栏正文先左后右，聚焦框不会跨栏扩展 |
| 快捷键 | `↑` / `↓` 移动聚焦框；3 行及以上每次移动行数的一半（向下取整）；`←` / `→` 调整行数 |
| 图表与图注常亮 | 图片、矢量图、图内标签和 figure legend 常亮，并从正文导航中排除；可手动补充区域 |
| 白天 / 黑夜 | 两套界面主题，自动记忆选择；PDF 图像保持原色 |
| 批注 | 选词高亮、添加与编辑笔记、删除批注 |
| 导出 | 带高亮及附注的 PDF、阅读记录 JSON、本文词汇 CSV |
| 备份恢复 | 对应同一 PDF 内容哈希的 JSON 记录可重新导入 |
| GPT 生物医学翻译 | 选中文字并结合附近上下文翻译，结果独立存入本文词汇本 |
| 文章词汇本 | 逐篇保存查询文字、译文、页码、上下文、来源、次数和失败状态 |
| GPT 侧栏 | 连接 OpenAI 官方 Responses API，支持多轮问答、错误提示、可选本页上下文与本地对话保存 |

方向键在输入框、笔记编辑框或文字选中时保留正常编辑行为。也可用阅读器底部按钮移动聚焦框。1–2 行时步长为 1；3 行为 1；4–5 行为 2；6–7 行为 3，以此类推；页末自动换页。换栏时先停在下一栏第一行，避免半框步长跳过开头文字；纯图页上下键用于翻页。竖排下载水印不参与正文行导航。

### 学术论文的版式识别

- 在合并相同基线的文字之前，先寻找重复的栏间空隙，兼容较窄栏间距和左右栏基线错开的页面。
- 正文按左栏自上而下、再读右栏；跨栏标题、摘要和摘要最后的短行保留在各自段落中。聚焦框到栏末停止扩展。
- 按 PDF 的原始字宽校正透明文字层，避免浏览器替代字体使选择范围和聚焦框伸进另一栏；行高仍按渲染后的文字边界测量。
- 根据图像对象、矢量绘图、标签密度和图注标记识别图文区域。图内文字与图注保持常亮，排除在逐行导航之外；图注仍可选词、翻译和批注。
- 对文档最多采样九页，识别重复页眉页脚，并结合位置排除页码、DOI、下载水印和出版脚注。正文中的 `Fig. S3B)` 等引用不按图注处理。
- 手动框选的图文区域也会从正文导航中排除。搜索和文本选择仍可用于图注。

逐行阅读依赖 PDF 文本层；扫描件需要先经过 OCR，本版不包含 OCR 引擎。自动识别使用版式规则，复杂跨页图注、文字路径化、特殊混排及无明确边界的图文仍可能需要手动补充常亮框。原始 PDF、高亮和笔记不会因版式识别被改写。

## 配置 GPT 翻译与答疑

翻译和答疑共用一套 OpenAI 凭据和模型，默认模型 ID 为 **`gpt-6.1-sol`**。两者使用独立请求和历史：翻译只写入文章词汇本；答疑只写入本文聊天记录。查询词汇不会进入聊天历史，也不会读取已有聊天。

1. 在设置的“GPT 翻译与答疑”区域填写自己的 **OpenAI API Key**。
2. 模型名称填写 `gpt-6.1-sol`；可点击“获取可用模型”确认自己的账户权限。不会自动替换成其他模型。
3. 保存后点击“测试模型连接”。测试发送一条不含文献的简短消息，会消耗少量 API 额度；只有实际响应成功才显示通过。
4. 选中文字后点击“翻译”或“问问 GPT”。不再需要有道账户或凭据。

翻译请求只发送选中文字（最多 5000 字符）和附近上下文（最多 1800 字符），采用生物医学翻译指令，并使用结构化输出区分译文与释义。译文未完成或格式无效时会显示失败，保留查询记录供手动重试。模型生成的术语释义可能有误，阅读时应结合原文核对。

默认只发送问题、选中引用和本篇文献中已经完成的对话历史；勾选“附上本页文字”后，才会额外发送当前页提取的文字（最多 18000 字符）。不自动上传完整 PDF 或图片。旧版本中的未发送问题仍是草稿，需要手动编辑并发送。

模型密钥通过 Windows DPAPI 加密，保存在本机 `model.bin`，不会进入文献备份或 GitHub。问答请求固定发往 `https://api.openai.com/v1/responses`，设置 `store: false`，不使用服务器会话 ID；服务商仍按其数据政策处理请求。应用显示真实回答、拒答、配额与网络错误，不自动重试，也不生成模拟回答。达到输出上限的回答会标注未完成。

参考 [OpenAI Responses 与会话状态文档](https://developers.openai.com/api/docs/guides/conversation-state)。

## 源码开发

需要 Node.js 20.19+，推荐使用维护中的 LTS 版本。

```sh
npm ci
npm run dev
```

在终端打印的 `http://127.0.0.1:5173` 打开网页开发版。

```sh
npm test          # 聚焦框、文件夹边界、PDF 导出、GPT 请求隔离与错误处理
npm run build    # TypeScript 检查与前端构建
npm run package  # Windows 上生成 release/BioFocus-Windows/
npm run desktop  # 构建并启动 Windows 程序
```

Windows 构建脚本从微软官方 NuGet 下载固定版本 WebView2 SDK，依据官方包目录中的 SHA-512 校验值验证下载内容，然后使用系统 .NET Framework C# 编译器生成程序。SDK 缓存放在被 Git 忽略的 `.native/`。其他系统可运行网页开发版和前端构建，Windows 桌面程序需要在 Windows 上编译。

原生检查可运行：

```powershell
.\release\BioFocus-Windows\BioFocus.exe --self-test .\native-test-result.txt
```

该检查覆盖 Windows 凭据加解密、文件夹路径边界、模型响应解析和翻译历史隔离，不访问真实 API。

### 网页版翻译与部署

开发版设置页将 OpenAI 凭据传给本机 Node 服务，仅保存在该进程内存中，重启需重新填写。开发服务仅监听回环地址，验证来源及 Host，不允许其他网站跨域配置。

`npm run build` 的 `dist/` 可部署到静态托管，支持 PDF 阅读、批注和本地保存。纯静态部署不包含 API 服务，翻译与答疑需要另接后端。

`npm start` 会在本机提供构建后的页面与服务接口。通过 `OPENAI_API_KEY` 和 `OPENAI_MODEL` 进程环境变量配置；未指定模型时使用 `gpt-6.1-sol`。示例 `.env.example` 不会被自动加载。生产模式禁止网页配置凭据。如需对外提供服务，必须自行增加访问认证、HTTPS、限流与用户隔离，避免多人共享账户密钥。

## 数据与隐私

应用源码和安装包不包含个人 PDF、原文路径列表、笔记、查词记录或服务密钥。默认示例文献及示意图由项目自行生成，明确标注为示例，不代表真实实验结果。

桌面数据在 `%LOCALAPPDATA%/BioFocus/`：

- `WebView/` 内的站点 IndexedDB 保存文献记录、词汇、聊天、高亮和笔记；这些普通阅读记录未由应用另行加密。
- `model.bin` 保存 Windows CurrentUser DPAPI 加密的模型凭据，界面不会读回密钥明文。
- `library.json` 保存文献文件夹设置；文件夹原 PDF 留在原位置。

词汇本和聊天不会自动出现在 ChatGPT App，也不会与其他设备同步。网页版阅读记录在当前站点的 IndexedDB / localStorage 中，与桌面版分别保存。

翻译和答疑都直接向 OpenAI 发送所需文字，请求使用 `store:false`，不创建远端会话记录。OpenAI API 数据默认不用于训练（除非主动选择分享）；常规滥用监测日志可能保留最多 30 天，法律或安全等例外可能更久。详见 [OpenAI 数据政策](https://developers.openai.com/api/docs/guides/your-data)。

建议定期导出阅读记录备份。删除应用数据、清除浏览器存储或更换站点域名可能导致无法访问原阅读记录。

## 技术结构

- `src/`：React + TypeScript，PDF.js 渲染、`layout.mjs` 正文与图文分离、文本选择、聚焦遮罩和阅读工作台。
- `windows/`：WinForms + WebView2 桌面壳、本机 API、文件夹监听和 DPAPI。
- `server/`：网页开发版服务、OpenAI 翻译与答疑请求及文件夹逻辑测试模块。
- `scripts/build-windows.mjs`：可复现的 Windows 构建入口。
- `tests/`：不依赖真实服务凭据的自动化测试。
